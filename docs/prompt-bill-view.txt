Instead of paymentStatus.orderId the unique bill Id should be POS bill number. After successful postbill or  submitOrderfastfoodbill API call, make a GET call to /api/kot/getbillnouseorderid where for parameter "OrderId" pass the merchantOrderID. The response will be as below:

{
  "orderId": "OMO2511121604218032636933",
  "MerchantOrderId": "ORID12112025160421",
  "POSBillno": "21345"
}

The POSBillNo is the unique billID. The bill URL can be constructured using the same. When the bill view page is access using

bill/view/<billID> 

When page loads API call is made to fetch details of the company - /api/kot/getcompanyinfobill
